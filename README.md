# 敷き詰めクエスト — Tiling Quest

3つのSVG原本の形を使って、平行移動・180°回転・鏡映を体験するパズルです。

## 遊び方

`index.html` をブラウザーで開きます。ビルド、外部ライブラリ、画像配信、データベースは不要です。

1. 白紙のエリアには、固定された「START」のタイルが1枚だけあります。
2. 下の「新しいタイル」から、同じ形を何枚でも取り出せます。
3. でっぱりとへこみを見ながら、となりへドラッグします。正しい境界の近くで離すとスナップします。
4. タイルを選び、ステージに応じて「回転」「反転」を使います。内部の顔・模様も一緒に変換されます。
5. 基準タイルから9枚以上を、たてにもよこにもつなぐとクリア。クリア後も追加できます。

正解位置の下地・マス目・シルエット・配置ヒントはありません。隣接位置を遠くから吸い寄せたり、向きや鏡映状態を自動で合わせたりもしません。

接続していない場所にも仮置きできます。配置済みタイルは再選択して動かせます。大きく重なる配置やエリア外へのドロップは取り消し、移動前のタイルを保ちます。「戻す」は選んだ1枚を取り除き、「やり直す」は基準の1枚に戻します。

- 余白をドラッグ：表示範囲を移動
- ＋ / −：表示倍率を変更
- 全体：仮置きも含めた全タイルを表示
- 新しいタイルを選んで盤面をタップ：ドラッグの代わりに配置
- PCの `R` / `F`：選択中のタイルを回転 / 左右反転
- `Escape`：ドラッグを取り消す

クリアには単なる横一列ではなく、隣り合う2行・2列を含む面が必要です。回転ステージには回転した仲間、鏡映ステージには鏡映した仲間が必要です。表示枚数は、基準タイルにつながっている枚数です。離れて仮置きしたタイルは数えません。

## SVG原本

| ステージ | 原本 | 使用する可視輪郭 | 変換 |
| --- | --- | --- | --- |
| 1 | `平行移動.svg` | `path5` | 平行移動のみ |
| 2 | `回転移動.svg` | `g8` 内の5パス | 平行移動・180°回転 |
| 3 | `鏡映.svg` | `path7-9`, `path7`, `path8`, `path6`, `path8-7` | 平行移動・180°回転・左右鏡映 |

原本ファイルは変更していません。ページ外の作図用図形を除き、輪郭の `d` は原文のまま保持し、元のグループ変換も反映しています。サイズ調整は等方拡大縮小のみです。

回転・鏡映の原本は複数の開いたパスで構成され、端点に最大約0.270572 SVG単位のずれがあります。利用者の了承に従い、原本の座標を動かさず、接続・重なり・クリア判定で微小な作図誤差を許容しています。内部の塗りと `clipPath` には各原曲線をそのまま結び、開いた端点間だけを閉じた補助パスを使います。表示する輪郭線は元のパスです。

厳密な隙間ゼロを証明したものではありません。原本の精度に合わせた数値検証と、実際の完成画面の確認を行っています。通常のPC・スマートフォン表示で、目立つ隙間は確認されませんでした。詳細は [幾何学と検証](docs/geometry.md) を参照してください。

## GitHub Pages

このフォルダーをGitHubリポジトリの公開ブランチへpushし、Settings → Pages でそのブランチの `/ (root)` を公開対象にします。ビルドは不要です。パスは相対指定で、リポジトリ配下のURLでも動作します。

## 開発・検証

```sh
# ローカル確認
python3 -m http.server 4173

# SVG原本から生成したデータが一致することを検証
python3 tools/build_tiles.py --check

# PlaywrightとGoogle Chromeを用意したNode.js環境で実行
node tests/browser.cjs
```

Playwrightは開発用テストでのみ使います。必要に応じて `NODE_PATH` にその `node_modules` を指定します。テスト先は `TEST_URL` で変更できます。

`tiles-data.js` は `tools/build_tiles.py` から生成しています。SVGを更新した場合は再生成と配置規則の再検証が必要です。ゲーム起動時のfetchを避けているため、ローカルファイルとしても開けます。

検証済み：原本パス保持、下地なし、3ステージの9枚配置、許容誤差内の面の被覆、誤った変換での重なり、自由配置、配置済みタイルの再移動、スナップ距離、大きな重なりの拒否、回転・反転、クリア、クリア後の追加、1枚の削除、リセット、ドラッグキャンセル、タッチ操作、320〜1440pxのレイアウト。

タッチはChromeのエミュレーションで検証しています。実機のiPad/iPhone・Safariは未検証です。

## ファイル

- `index.html`, `style.css`：画面とレスポンシブ表示
- `game.js`：供給、自由配置、操作、描画、振り返り
- `geometry.js`：剛体変換、非表示の隣接規則、接続・重なり判定
- `tiles-data.js`：原本から生成した輪郭・塗り用データ
- `tools/build_tiles.py`：原本抽出と一致確認
- `tests/browser.cjs`：ブラウザー自動テストと幾何学的検証
