# 原本輪郭と配置規則

## 1. 原本を保持する範囲

原本3ファイルのハッシュを生成データに記録しています。ゲーム内の輪郭 `path` は原本の `d` をそのまま持ちます。原本の回転・鏡映・グループ移動は合成変換行列として適用します。頂点の丸め、輪郭の矩形化、曲線の近似描画、異方拡縮は行いません。

各ファイルは210 × 210のページの外にも作図用のパスや長方形を含みます。ゲームに使用するのはページ内の完成輪郭だけです。

回転・鏡映の輪郭を構成する5本のパスは開いています。内部の色・模様を切り抜く補助パスでは、原本の直線・3次ベジェ・楕円弧を解析的に変換・必要に応じて逆向きに連結しています。開いた端点間にのみ短い線を追加します。この補助パスに輪郭線は描きません。元の5本の線を別途描画するため、見える輪郭の座標は変わりません。

## 2. 平行移動

`平行移動.svg#path5` を使用します。基本周期は原本の正方形に対応する約69.6176単位です。

- 横方向：左右の斜めの切り欠き・出っ張りが平行移動で対応。
- 縦方向：上辺と下辺のぎざぎざが同じ向きで対応。
- すべてのタイルを元の向きのまま配置。

非表示の位置は整数 `c, r` に対し、SVG座標で `(c × 69.6176, r × 69.6176)` の移動です。原本の微小な作図誤差は残しています。

## 3. 180°回転

`回転移動.svg#g8` の `path7-9`, `path7`, `path8`, `path6`, `path8-7` を使用します。

- 左右の境界は約 `(69.68006, 0.14145)` の平行移動で一致。
- 上辺は、凹んだ半円と出っ張った半円から構成され、上辺全体の中点で180°回すと対応。
- 下辺の折れ線も、その全体の中点で180°回すと対応（作図誤差内）。

上辺の両端の中点を `A`、下辺の両端の中点を `B` とし、タイルの変換中心を `(A+B)/2` に取ります。およその座標は次のとおりです。

- `A = (119.97228, 68.90175)`
- `B = (120.10933, 138.75150)`
- 横周期 `U = (69.68006, 0.14145)`
- 縦周期 `V = B-A ≈ (0.13705, 69.84974)`

位置 `cU + rV` に、偶数行では元の向き、奇数行では180°回転したタイルを置きます。横一列は平行移動でつながりますが、面として上下へ広げるには上下の形の違いから180°回転が必要です。

## 4. 鏡映

`鏡映.svg` のページ内5パスを使用します。回転ステージと異なり、右境界の斜めの切り欠きが左境界に対して上下を入れ替えた構造です。

横の仲間をつなぐには上下鏡映が必要です。UIでは左右鏡映 `F` と180°回転 `R` を用意し、上下鏡映は `RF` として作れます。列・行が隣に進むと向きが次のように変わります。

| 行 / 列 | 偶数列 | 奇数列 |
| --- | --- | --- |
| 偶数行 | 元の向き | 左右鏡映＋180°回転（上下鏡映） |
| 奇数行 | 180°回転 | 左右鏡映 |

これは形と内部の絵の両方へ同じ行列を適用します。位置は横約69.68006、縦約69.84974単位の周期です。作図誤差による微小な差を座標修正で隠さず、接続判定で許容しています。

## 5. スナップと接続

位置の候補は無限格子として内部に持ちますが、画面には描画しません。基準タイルにつながるタイルの隣だけを候補とします。

- 位置：マウス約21px、タッチ約28px以内。ただし基本周期の0.34倍を上限とする。
- 向き・鏡映状態：候補と一致している必要がある。自動変換しない。
- 大きな重なり：拒否する。
- 遠い位置：スナップせず、その場所に仮置きする。

接続は基準タイルからのグラフ探索で判定します。9枚以上が連結し、その中に隣り合う2行・2列の小さな面があり、各ステージの必要な変換を含めばクリアです。決まった9箇所への穴埋めではなく、基準の上下左右へ自由に広げられます。

## 6. 作図誤差と確認結果

厳密な幾何学的隙間ゼロの主張はしません。元データの精度と、利用者が了承した微小誤差を前提とした実装です。

- 回転・鏡映の開いた端点の最大距離：約 **0.270572 SVG単位**。
- 下辺を中点で180°回したときの境界の不一致：約 **0.2217 SVG単位**（原曲線のサンプルと線分間距離による計算）。
- 大きな重なりの境界許容幅：基本周期の0.0047倍、約 **0.33 SVG単位**。輪郭は移動・変形しない。
- 正しい3 × 3配置：許容値を超えた重なりなし。中央の面のサンプル点で大きな欠落なし。
- 中央被覆サンプルで見つかった未被覆点から最近傍の境界までの最大距離：ステージ1・2は0、ステージ3は約0.061 SVG単位。これはサンプル測定であり、全域の最大隙間の厳密上界ではない。
- 同じ配置位置で必要な回転・鏡映を外すと、大きな重なりが発生することを確認。
- PC・スマートフォン相当の完成画面では、目立つ隙間なし。非常に大きく拡大すれば原本の微小誤差は残る。

ブラウザー検証では原本パスの文字列・変換行列・SHA-256も確認します。描画は原曲線を使い、重なり・面の被覆の検証にはその曲線から抽出した点列を使っています。一般の任意の位置・角度を含む全敷き詰めの不可能性を証明するものではありません。
